ClaudeCode使用记录

发表于 2026-06-02 分类于 工具使用 ， 效率工具 阅读次数： 本文字数： 2.4k 阅读时长 ≈ 2 分钟

一些命令记录，由GPT补充生成

指令 / 快捷键 作用 典型场景
/compact 压缩对话上下文，保留核心摘要 对话过长 token 超限时
/clear 清空所有对话历史，全新开始 切换到完全不同的任务时
claude -c 启动时恢复上一次对话 次日继续昨天未完成的工作
Ctrl+B 将当前任务挂到后台运行 让 AI 后台编译，前台讨论下一步
ESC×2 (/rewind) 回退或总结（回滚 AI 操作） AI 改错了代码，快速撤销
↓ / /tasks 管理后台任务（查看/停止） 检查后台编译/测试是否完成
Ctrl+T 显示/隐藏任务列表面板 查看 Claude 创建的任务进度
Alt+V 粘贴图像（Windows） 截图粘贴给 Claude 分析 UI/报错
/memory 打开并编辑 CLAUDE.md 修改项目规则或个人偏好
/init 自动生成 CLAUDE.md 初稿 新项目首次接入 Claude Code
/hooks 配置工具钩子（自动化触发） 写文件后自动 prettier 格式化
+Enter 输入框内换行（不发送消息） 输入多行代码或多段需求描述时
Shift+Tab 循环切换三种工作模式 从 Plan Mode 切到 Accept Edits 执行

Claude Code 常用命令速查表

指令 / 快捷键 作用 典型场景
/compact 压缩对话上下文，保留核心摘要 对话过长，避免上下文超限
/clear 清空当前会话 开启全新任务
claude -c 恢复最近一次会话 第二天继续开发
claude 启动 Claude Code 开始工作
claude . 在当前项目目录启动 打开当前工程
claude /path/project 打开指定项目 切换工程
Ctrl+B 后台运行当前任务 编译、测试耗时较长
/tasks 查看后台任务 查看运行状态
↓ 快速打开任务列表 检查后台工作
Ctrl+T 显示/隐藏任务面板 查看所有任务
ESC ESC 回退上一步操作 AI改坏代码时
/rewind 回滚到之前状态 撤销最近操作
Shift+Tab 切换工作模式 Plan ↔ Edit ↔ Accept
Enter 发送消息 正常交互
Shift+Enter 输入框换行 多行需求
Ctrl+C 中断当前执行 停止编译/测试
Ctrl+L 清空终端显示 保持界面整洁
Alt+V 粘贴截图（Windows） 分析错误截图
拖拽文件 上传文件 分析日志、代码

工作模式（Shift+Tab切换）

模式 作用 特点
Plan Mode 规划模式 只分析，不改代码
Edit Mode 编辑模式 生成修改建议
Accept Edits Mode 执行模式 自动修改文件

实用技巧

技巧 说明
先 Plan 再 Edit 降低误改代码风险
大项目先 /compact 节省上下文
使用 CLAUDE.md 固定团队规范

善用 @git diff 快速Review
善用 @文件名 精准定位问题
